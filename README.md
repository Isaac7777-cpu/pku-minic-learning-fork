# pku-minic-learning-fork

I am trying to learn the compiler as described here: [pku-minic](https://github.com/pku-minic). Also, I am trying to be greedy in a sense that I want to implement it in both C++ and Rust because I just want to see how the two languages differ. It is clear that the `cpp/` directory would, naturally, contain the code for C++ implementation while the `rust/` directory would contain the code for Rust implementation.

## Resource Sharing

Recently, I realised there are people cloning this repository and I am really happy to see this as a form of information sharing. However, please note that the code here is, as stated in the MIT license, not gauranteed to work and it should not be taken as the solution as I am also new to compiler development (that's why it is a `learning-fork`). **Also, if this is part of your university project, please try to attempt it yourself.**

I happy to take questions about implementation details via issues, emails, and other ways that you can reach out to me. Also, if you spot a bug, please don't hesitate to raise an issue/PR to fix it -- it would be much appreciated!
